The world as it starts, built by hand with the framework around it rather than by a daily run.

**What is there.** One island on a square of ground 260 units across, shaped by a single height
function that everything else shares: the terrain mesh samples it, the scatterers place on it,
the water meets it and the camera walks on it. Five features: sky, sun and fog; the terrain; the
sea; boulders; grass tufts. Four postcard views, `hero` first.

**What it costs.** Seven draw calls on both tiers (five features, plus the terrain and the
boulders again in the shadow pass). 149k triangles on desktop, 55k on mobile. The build is 44 KB
of its own code beside the shared copy of three.

**What it is for.** To prove every part of the loop before the first daily run: features as
modules on a fixed clock, a camera that tours, orbits and walks, a capture harness the gate can
drive, and a build that publishes as an iteration.

**Next.** The roadmap's first item: write the Direction in `VISION.md`. The seed has no opinion
about what this place should become, and that is the first thing it needs.
