# Requests

What the owner would like to see. The curator reads this before choosing the day's change:
open requests come before its own ideas.

To ask for something, add a line under **Open** and commit it to `main` (editing this file on
GitHub is enough). Say what you want to see, not how to build it.

The curator ticks a request off when it lands, with the date and the journal entry, and moves it
under **Done**. If a request cannot be met as asked, it says why in `PROPOSALS.md`.
